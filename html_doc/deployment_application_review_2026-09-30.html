Change-history assessment

The sequence from 576f124 through d4a3e9c is additive and traceable: private OCI state, profile selection, Docker persistence, Docker-safe updates, MySQL Shell inclusion, then CA compatibility. No destructive migration or broad rollback was found. The main concern is release discipline: the latest OCI profile-picker work is active locally but has not yet received the same tests, version update, commit, and push as the preceding changes.

Recommended acceptance sequence

  1. Complete and release the OCI Config profile-picker work with tests and documentation.
  2. On Docker: save two OCI profiles, switch profiles, confirm non-secret fields load, key is preserved, test access, create PAR, and run a small dump/load.
  3. On clean OL9 and Ubuntu hosts: run setup twice, validate service restart, local-admin forced password change, MySQL Shell Innovation, Object Storage access, and Auto-Update.
  4. Define an audited Docker MySQL Shell update policy and automate verification.
