MySQL Shell Dump/Load Validation

  • Configure and test the target under Admin → Setup Object Storage. DB Console uses the Compute Instance Principal; OCI API-key configuration is not supported.
  • Create reusable PAR entries under MySQL Shell → PAR Setup. Read/write PARs support dump and load; read-only PARs support load only.
  • Create reusable dump and load mysqlsh option sets under MySQL Shell → Option Profiles.
  • Dump Schemas requires at least one non-empty schema name. All operations use the active authenticated MySQL connection profile.
  • Jobs run through the DB Console-installed mysqlsh binary. PAR bearer URLs remain server-side and are never displayed in operation previews.
  • Confirm database privileges, Object Storage IAM policy, free disk space, and target compatibility before submitting production jobs.
